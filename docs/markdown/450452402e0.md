# 查询大盘k线数据

> 来源: https://doc.steamdt.com


## 查询大盘k线数据


### 请求参数

- 
- 
- 

```
{
    "type": 1
}
```

### 请求示例代码

```
curl --location 'https://open.steamdt.com/open/cs2/broad/v1/kline' \
--header 'Content-Type: application/json' \
--data '{
    "type": 1
}'
```

### 返回响应

- 
- 
- 

```
{
  "success": false,
  "data": [
    [
      {}
    ]
  ],
  "errorCode": 0,
  "errorMsg": "",
  "errorData": {},
  "errorCodeStr": ""
}
```

# 通过marketHashName批量查询饰品价格

> 来源: https://doc.steamdt.com


## 通过marketHashName批量查询饰品价格


### 请求参数

- 
- 
- 

```
{
    "marketHashNames": [
        "string"
    ]
}
```

### 请求示例代码

```
curl --location 'https://open.steamdt.com/open/cs2/v1/price/batch' \
--header 'Content-Type: application/json' \
--data '{
    "marketHashNames": [
        "string"
    ]
}'
```

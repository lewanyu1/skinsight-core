# 通过ASMD参数查询磨损度相关数据

> 来源: https://doc.steamdt.com


## 通过ASMD参数查询磨损度相关数据


### 请求参数

- 
- 
- 

```
{
    "s": 0,
    "m": 0,
    "a": 0,
    "d": "string",
    "notifyUrl": "string"
}
```

### 请求示例代码

```
curl --location 'https://open.steamdt.com/open/cs2/v2/wear' \
--header 'Content-Type: application/json' \
--data '{
    "s": 0,
    "m": 0,
    "a": 0,
    "d": "string",
    "notifyUrl": "string"
}'
```

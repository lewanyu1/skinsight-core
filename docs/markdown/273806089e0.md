## 通过检视链接生成检视图,前提是已经获取到饰品的磨损度


### 请求参数

- 
- 
- 

```
{
    "notifyUrl": "string",
    "inspectUrl": "string"
}
```

### 请求示例代码

```
curl --location 'https://open.steamdt.com/open/cs2/v1/inspect' \
--header 'Content-Type: application/json' \
--data '{
    "notifyUrl": "string",
    "inspectUrl": "string"
}'
```
